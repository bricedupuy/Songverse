# RNNoise model

`bd.rnnn` is the "beguiling-drafter" model from
[rnnoise-models](https://github.com/GregorR/rnnoise-models) (2018-08-30),
trained for a voice - speech and the other sounds people make - against the
noise of a recording. ffmpeg's `arnndn` filter uses it to clean up a sung
take (issue #132). Its authors note the models aren't subject to copyright.
